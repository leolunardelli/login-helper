# 🔐 Login Helper

Sistema de autenticação responsivo com validação de formulário.

## 🚀 Tecnologias
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript ES6+

## 💡 Funcionalidades
- Validação de email em tempo real
- Feedback visual de erros
- Design responsivo mobile-first
